## 🚀 How to Execute the Rebuild

1. Review the vision and design tokens in `01` and `03`.
2. When starting code generation, copy the exact prompt from **`06_IMPLEMENTATION_ROADMAP_AND_AI_PROMPTS.md`** for Phase 1.
3. Validate each phase against the automated test matrices in `05` before progressing.
